# 🧵 Ai Marketplace (React + Vite)

**Unified Vision Capital is an Investment Banking firm based in Noida. We work with companies to raise funds, manage/advise transactions, and connect them with the right investors.**

This is the frontend application for **UV Capitals**, a modern finance company platform. Built with **React** and **Vite**, it provides a fast and responsive user interface for customers and admins.

---

## ✨ Features

- ⚡ Lightning-fast development with Vite  
- 🧩 Modular React components and hooks  
- 🔐 JWT-based authentication and role-based UI  
- 📦 Product listings, filtering, and detail views  
- 🌐 API integration with the Ratan Textile backend  
- 💅 Styled using CSS Modules / Bootstrap / styled-components *(customizable)*

---

## 🛠️ Tech Stack

- **Frontend:** React (with Vite)  
- **Routing:** React Router  
- **State Management:** Context API / Redux *(based on setup)*  
- **Auth:** JWT Token Handling  
- **API Client:** Axios  
- **Styling:** Bootstrap CSS / CSS Modules *(choose as needed)*  
- **Form Handling:** React Hook Form   
- **Environment Config:** dotenv
